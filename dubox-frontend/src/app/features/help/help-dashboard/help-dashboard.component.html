System Requirements

Review the supported browsers, operating systems, and data centers for DuBox products (Projects, Quality Control, Teams, Materials, Cost Management, Schedule, Reports, Factories, BIM, and Admin modules).

Note: Since DuBox is a web-based product, there are no specific hardware requirements. A stand-alone video card is recommended when using the 3D Viewer, but RAM and CPU requirements depend on project size.

Supported Browsers

Important: 64-bit browsers are recommended for optimal viewing experience.

The latest versions of the following browsers are recommended. Otherwise, browser versions that are no more than a year old are strongly advised for continued support.

  • Chrome (Recommended)
  • Firefox
  • Safari
  • Edge
Note: Internet Explorer 11 is not supported for use with DuBox products.

Operating Systems

There are no desktop operating system requirements for DuBox products since they are web-based.

Detailed guides with screenshots to help you get started with DuBox features

How to Create a New Project

Projects

Follow these steps to create and configure a new construction project in DuBox.

1

Navigate to Projects & Click "New Project"

From the main sidebar, click on Projects to access the projects dashboard. You'll see all your existing projects with their status (Active, On Hold, Completed, etc.). Click the "+ New Project" button in the top-right corner to start creating a new project.

Projects page showing all active projects and the "New Project" button

2

Fill in Project Information & Timeline

The Create New Project form opens with a step indicator showing Step 1: Project Details. Fill in the following required information:

📋 Project Information
  • Project Name: e.g., "Dubai Marina Tower Construction"
  • Project Code: e.g., "DUB-2024-001" (unique identifier)
  • Client Name: e.g., "Amana Contracting"
  • Location: Select from dropdown (KSA, UAE, etc.)
📅 Timeline & Schedule
  • Planned Start Date: Select start date (mm/dd/yyyy)
  • Duration (days): e.g., 180 days
  • Projected End Date: Auto-calculated based on duration
  • Project Value: e.g., 5000000 (total estimated value)
  • Project Manager: Select from dropdown

Project Information and Timeline sections with all required fields

3

Add Additional Details & Configuration

Scroll down to complete the optional but recommended additional information:

📝 Additional Details
  • Project Description: Enter detailed description of project scope, objectives, and key deliverables
  • BIM Link: Add link to BIM model if available (e.g., https://example.com/bim-model)
  • Conditional Approval: Check the box if you want to "Allow project completion with conditional approval checkpoints"
⚙️ Project Configuration

Optionally configure buildings, floors, zones, and units. You can add these items one at a time or multiple comma-separated values (press Enter or click Add).

Once all information is entered, review your details and click the "Create Project" button at the bottom-right. You can also click "Cancel" to discard changes.

Additional Details section with Project Description, BIM Link, and Project Configuration

Success! Your project has been created and will appear in the Active projects list. You can now add boxes, teams, activities, and start tracking progress.

How to Submit a Work Inspection Request (WIR)

Quality

Follow this comprehensive guide to create and submit quality control inspection requests (WIR) for your construction activities.

1

Navigate to Box Activities & Start Stage

Go to your box details page and click on the Activities tab. You'll see all stages with their activities, assigned teams, and status. Locate the stage you want to inspect (e.g., Stage-1 with QA/QC activities). Click the green "QA/QC" button to open the inspection modal.

📋 QA/QC Inspection Modal

A modal will appear showing:

  • Stage Code: e.g., WIR-1
  • Box Tag: e.g., 190-B02-GF-S2-2
  • Activity: e.g., Box Closure
  • Box Name: e.g., 002
  • Status: PENDING (orange badge)

You can add optional Inspection Notes in the text area. Click "Start Stage" button to begin the inspection process, or "Reject" if there are issues.

QA/QC Inspection modal showing stage details with Start and Reject options

2

View Activities & Add Stage Checkpoint

After starting the stage, you'll see the Activities page with a detailed table showing all activities for this box. Each stage row (Stage-1, Stage-2, Stage-3) shows:

📊 Stage Information Display
  • Stage Badge: Stage number with color coding
  • QA/QC Team: Assigned team (e.g., QA/QC)
  • Clearance/Stage: Stage type (CLEARANCE / STAGE)
  • Assigned to: Person responsible (e.g., Mamdouh Salem, QC Engineer)
  • Location Info: BAY: E, ROW: 10, POSITION: E-10
  • Stage Name: e.g., "Release from Assembly - Stage-1"
  • Status Badge: PENDING (yellow)
  • QA/QC Button: Green button with checkmark
  • Add Checkpoint: Orange "+ Add Checkpoint" button

Click the orange "+ Add Checkpoint" button next to the QA/QC button to create a new inspection checkpoint for this stage.

Activities table showing stages with Add Checkpoint button for quality control

3

Create Stage Checkpoint - Define Inspection Scope

The QA/QC Activity Approval Checklist workflow begins. You'll see a progress indicator at the top showing 4 steps. The first step is to Create Checkpoint to capture the WIR context.

📝 Step 1: Create Stage Checkpoint

Fill in the checkpoint information:

  • BOX TAG: Pre-filled (e.g., 190-B02-GF-S2-2)
  • STAGE NUMBER: Pre-filled (e.g., WIR-1)
  • ACTIVITIES INCLUDED: Shows (4 Activities) - Box Closure, Box Closure, Box Closure, Box Closure
  • Stage Name: Auto-generated (e.g., "WIR-1 - 4 Activities: Box Closure, Box Closure, Box Closure, Box Closure")
  • Stage Description: Text area for detailed description of the checkpoint
  • Inspector (Optional): Dropdown to select the inspector

The form provides clear context about which activities will be inspected. After filling in the details, proceed to the next step to add checklist items.

Step 1: Create Stage Checkpoint showing checkpoint information and included activities

4

Add Checklist Items - Define Inspection Scope

Now in Step 2: Add Checklist Items, you'll define what needs to be inspected for this stage checkpoint.

📋 Inspection Request Overview

The page shows the inspection request summary:

  • WIR-1 • 4 Activities
  • BOX TAG: 190-B02-GF-S2-2
  • REQUESTED BY: Mamdouh Salem
  • REQUESTED DATE: Feb 16, 2026 12:57 PM
  • INSPECTOR: Pending assignment
  • Status: Pending (yellow badge)
✅ Checklist Designer

The Checklist Designer section allows you to create or edit inspection checkpoints. You have two options:

  • "+ Add Predefined Items" button (blue) - Select from pre-configured checklist templates
  • "Review" button (blue) - Review and finalize your checklist

Currently showing: 0 existing item(s) - "No checklist items added yet"

Click "+ Add Predefined Items" to select from the predefined checklist templates, or you can manually create custom checklist items.

Step 2: Add Checklist Items showing inspection request details and checklist designer

5

Add Predefined Checklist Items

The Add Predefined Checklist Items page displays organized checklists grouped by sections. This allows you to quickly select standard inspection items relevant to your WIR checkpoint.

📚 Select Predefined Checklist Items

At the top, you'll see:

  • Title: WIR-1 • WIR-1 - 4 Activities: Box Closure, Box Closure, Box Closure, Box Closure
  • Selected Counter: "3 item(s) selected" (turquoise badge)
  • Expand All / Collapse All: Buttons to expand/collapse all sections
  • Select All: Button to select all items
📑 Checklist Sections

The main checklist displayed is "Construction of Precast Concrete Modular at Factory Checklist" (Code: ASA-IMS-FRM-13-081) with expandable sections:

  • A. General - 3 item(s)
  • B. Preparation & Setting Out - 3 item(s)
  • C. Erection / Assembling of Precast Element - External Walls - 3 item(s)
  • C. Erection / Assembling - Floor Slab(s) - 7 item(s)
  • C. Erection / Assembling - Internal Partition - 4 item(s)
  • C. Erection / Assembling - Top Slabs - 6 item(s)
  • Civil Works - 2 item(s)

Each section has a "Select Section" or "Deselect Section" link to quickly select/deselect all items in that section.

Browse through the sections, select the relevant checklist items by clicking on sections or individual items, then click "+ Add Selected Items (3)" at the bottom to add them to your inspection checklist. Click "Cancel" to go back without adding items.

Predefined checklist items grouped by sections with selection options

6

Review & Sign-off - Validate Checklist

Now in Step 3: Review & Sign-off, you can validate and approve the inspection checklist items. This is the critical quality control validation step.

ℹ️ Admin Override Notice

A blue info banner appears if you're not the assigned inspector: "You are not the assigned inspector, but as a System Admin you have full access to review and modify this checkpoint."

📸 Inspection Photos

Upload inspection evidence:

  • URL: Add image links
  • Upload: Upload images (JPG, PNG - Max 5MB each)
  • Camera: Take photos directly
✅ Checklist Validation

The checklist displays selected items from "CONSTRUCTION OF PRECAST CONCRETE MODULAR AT FACTORY CHECKLIST" with 3 item(s). Each item shows:

  • SEQ: Sequence number (1, 2, 3...)
  • CHECKPOINT DESCRIPTION: Description of what to inspect
  • STATUS: PENDING (yellow badge)
  • ACTIONS: "Review" button (green) for each item

Quick actions at the top:

  • "Approve All (3)" - Approve all items at once
  • "Reject All (3)" - Reject all items at once
🎯 Inspector Notes & Final Decision

On the right side panel:

  • Status Overview: Shows Requested date and Inspection/Approval status
  • Inspector Role: e.g., "QC Engineer - MEP" (optional, max 100 characters)
  • Comments: Text area for general inspection notes (0/1000 characters)
  • Final Decision: Choose Approved, Conditional Approval, or Rejected

Review each checklist item by clicking "Review", add photos if needed, fill in inspector notes, select your final decision, then click "Submit Decision" to complete the inspection. Click "Close" to exit without submitting.

Step 3: Review & Sign-off showing checklist validation, photos upload, and final decision panel

7

Quality Issues (Optional) - Log Defects & Observations

The final step, Step 4: Quality Issues (Optional), allows you to log defects, non-conformances, or observations that need follow-up outside of the main review workflow.

⚠️ Quality Issues Tracking

This section displays:

  • Status: Inspection Request shows "Approved" (green badge)
  • Inspection Request Info: WIR-1 • 4 Activities with all details (Box Tag, Requested By, Date, Inspector)
  • Quality Issues Panel: Warning icon with description "Track and manage inspection defects, non-conformances, and observations"
  • Issues Counter: "0 Issues" displayed
  • Action Buttons: "+ Add Quality Issue" (blue button) to add new issues
📝 When to Add Quality Issues

Use this section when you find:

  • Material defects or non-conformances
  • Workmanship issues requiring correction
  • Safety observations
  • Items requiring follow-up inspections
  • Conditional approval items that need tracking

If there are no issues, the screen shows "No Quality Issues Logged" with a clock icon and prompts to "Start by adding quality issues to track defects and observations" using the "+ Add Your First Issue" button.

Once you've addressed any quality issues (or if there are none), click "Close" to complete the WIR workflow. Your inspection is now submitted and will be tracked in the system.

Step 4: Quality Issues (Optional) for logging defects and observations outside the main review workflow

Inspection Complete! Your Work Inspection Request (WIR) has been submitted successfully. The inspection data is now recorded in the system and will be visible in the Quality Issues dashboard for tracking and reporting.

How to Create and Manage Crews

Teams

Learn how to create and manage construction crews for your projects. Crews are organized teams assigned to specific departments and trades.

1

Navigate to Crews Dashboard

Access the Crews Dashboard from the main sidebar. The dashboard displays a comprehensive overview of all your construction crews.

🔍 Search and Filter Options

Below the statistics, you'll find powerful search and filter tools:

  • Search Bar: Search by code, name, department, trade, or leader
  • All Departments: Dropdown filter to view crews by specific department
  • All Trades: Dropdown filter to view crews by specific trade
  • Show Active Only: Checkbox to display only active crews
📋 Crews List Table

The main table displays detailed information for each crew with the following columns:

  • CODE: Unique crew identifier
  • NAME: Descriptive crew name
  • DEPARTMENT: Organizational unit
  • TRADE: Specialized trade
  • CREW LEADER: Assigned team leader
  • CREW SIZE: Number of members (shown as blue badges)
  • STATUS: Active or Inactive
  • CREATED DATE: When the crew was created
  • ACTIONS: View, Delete, and Edit buttons

To create a new crew, click the green "+ Create Crew" button in the top-right corner of the dashboard.

Crews Dashboard showing summary statistics, search filters, and crews list table

2

Create New Crew - Fill in Details

After clicking "+ Create Crew", you'll be taken to the Create New Crew page. The page features breadcrumb navigation (Crews > Create New Crew) and a clean form layout.

📄 Form Header

The page header displays:

  • Icon: Green circular icon with crew/team symbol
  • Title: "Create New Crew"
  • Subtitle: "Add a new crew to manage your construction workforce"
📝 Crew Information Form

The form section titled "Crew Information" contains four fields in a two-column layout:

  • Crew Code * (Required)
    • Unique identifier for the crew
    • Placeholder: "e.g., ASM-A"
    • Character limit: 0/50
  • Crew Name * (Required)
    • Full name of the crew
    • Placeholder: "e.g., Assembly Crew A"
    • Character limit: 0/200
  • Department * (Required)
    • Organizational unit
    • Dropdown: "Select Department"
    • Options include: IT, Management, Engineering, Construction, Quality, Procurement, HSE, DuBox, DuPod
  • Trade (Optional)
    • Specialized trade (optional)
    • Dropdown: "Select Trade"
    • Options include: Assembly, Mechanical, Electrical, Finishing, Structural, MEP, Other
✅ Completing the Form

To create the crew:

  • Enter a unique Crew Code following your organization's naming convention
  • Enter a descriptive Crew Name that clearly identifies the team's purpose
  • Select the appropriate Department from the dropdown
  • Optionally select a Trade to specify the crew's specialized area
  • Click "Create Crew" (teal button) to save the new crew
  • Click "Cancel" to discard changes and return to the dashboard

Create New Crew form with all required and optional fields for crew creation

Crew Created Successfully! Your new crew has been added to the system and is now visible in the Crews Dashboard. You can now add members to the crew, assign a leader, and assign the crew to project activities for effective workforce management.

How to Manage Project Costs & Cost Codes

Cost Management

Learn how to track and manage construction costs using the comprehensive Cost Management module. This includes managing cost code structures, project-specific costs, and human resource codes (HRC) for complete financial oversight.

1

Navigate to Cost Codes Master

The Cost Codes Master provides a comprehensive catalog of standardized cost codes used across all projects. Access this view by clicking the "Cost Codes Master" tab in the Cost Management module.

📑 Module Tabs

The Cost Management module has three main tabs at the top:

  • Project Cost: View and manage costs for specific projects
  • Cost Codes Master: Master catalog of all cost codes with hierarchical structure (currently selected)
  • HRC Code: Human Resource Codes for labor cost tracking
🔍 Search & Filter Cost Codes

The Search & Filter Cost Codes section provides powerful filtering capabilities:

  • Cost Code: Search by specific cost code identifier
  • Cost Level 1: Filter by first level of cost hierarchy (dropdown with "All Levels" option)
  • Cost Level 2: Filter by second level of cost hierarchy (dropdown with "All Levels" option)
  • Cost Level 3: Filter by third level of cost hierarchy (dropdown with "All Levels" option)
  • Level 1 Description: Search by description text for level 1
  • Level 2 Description: Search by description text for level 2
  • Level 3 Description: Search by description text for level 3
  • Status: Filter by active/inactive status (dropdown with "All Status" option)
  • Search Button: Apply all selected filters to the results
📊 Cost Codes Hierarchy Table

The main table displays the complete cost code structure with hierarchical levels. Each row represents a unique cost code combination:

  • COST CODE: The complete cost code identifier
  • COST CODE LEVEL 1: First level code number
  • LEVEL 1 DESCRIPTION (= A): Description for level 1 category
  • COST CODE LEVEL 2: Second level code number
  • LEVEL 2 DESCRIPTION (= B): Description for level 2 subcategory
  • COST CODE LEVEL 3: Third level code number
  • LEVEL 1 DESCRIPTION (= A.B.A): Description for level 1 in context
  • LEVEL 2 DESCRIPTION (= B.B.B): Description for level 2 in context
  • LEVEL 3 DESCRIPTION (= ABABA): Detailed description for the specific level 3 cost item
  • STATUS: Active or inactive status badge

The hierarchical structure allows for detailed cost breakdown and categorization, from general procurement categories down to specific items like project documents, certifications, and schedules.

➕ Adding New Cost Codes

Click the green "+ Add Cost Code" button in the top-right corner to create a new cost code in the master catalog.

Cost Codes Master showing hierarchical cost structure with multi-level filtering and search capabilities

2
