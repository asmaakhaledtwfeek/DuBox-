Project Material Management

Projects use material templates to define required materials. Individual materials are selected when creating or configuring box types. This ensures consistency and simplifies material management across the project.

  • Templates: Assign one material template to this project above
  • Box Types: When creating boxes, materials will be available based on assigned templates
  • Customization: Box-specific material templates can override project-level templates
